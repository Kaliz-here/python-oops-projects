Project 2: Library Management System

Create a Class: Book
Attributes
title
author
isbn
available (default = True)
borrower_name (default = None)


Methods

1. borrow_book(borrower_name)
Check if the book is available.
If available:
Set available = False
Store the borrower's name.
Print "Book borrowed successfully."
Otherwise:
Raise an error or print "Book is already issued."


2. return_book()
Set: available = True
borrower_name = None
Print "Book returned successfully."


3. __str__()

Example output:
Title : Python Programming
Author : John Smith
ISBN : 123456789
Status : Available

or

Title : Python Programming
Author : John Smith
ISBN : 123456789
Status : Issued to Rahul
